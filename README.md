# scop

## Description

scop is the 42 introduction to 3D rendering. The goal of the project is to write
a small 3D model viewer from scratch: parse a Wavefront `.obj` file and display
the model in a window using OpenGL.

The project includes:

- a hand-written `.obj` / `.mtl` parser (vertices, texture coordinates,
  normals, faces, materials)
- a small custom math library (`mymath`) instead of glm
- a shader-based rendering pipeline with diffuse texture mapping
- a first-person camera and multiple rendering modes

It builds on GLFW for windowing/input and GLEW for OpenGL function loading.

## Instructions

### Dependencies

- C++17 compiler (`g++`) and `make`
- OpenGL
- GLFW 3
- GLEW
- `stb_image.h` (already bundled in `external/`, used by the bonus build)

On Debian/Ubuntu:

```sh
sudo apt install build-essential libglfw3-dev libglew-dev libgl1-mesa-dev
```

### Build

```sh
make          # builds ./scop
make bonus    # builds ./scop_bonus (texture loading via stb_image)
```

### Run

```sh
./scop <model.obj> [scale]
```
or
```bash
./scop_bonus <model.obj> [scale]
```

Examples:

```sh
./scop models/teapot.obj
./scop models/42.obj 1.0
```

The optional `scale` argument scales the model (default `1.0`).

### Controls

| Key / input            | Action                          |
| ---------------------- | ------------------------------- |
| W A S D                | Move the camera                 |
| Left mouse drag        | Look around                     |
| Right mouse drag       | Rotate the model                |
| Space                  | Cycle render mode (color, texture, points, wireframe) |
| Esc                    | Close the window                |

### Make targets

- `make run_check` / `make run_check_bonus` — run the program under Valgrind
  with the leak-check flags from the Makefile
- `make clean` / `make fclean` / `make re` — standard cleanup/rebuild targets
